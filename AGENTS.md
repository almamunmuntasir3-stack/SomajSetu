# AGENTS.md

## Repo shape (two separate git repos)
- Root and `shomajsetu/` are separate git repos. Root tracks the app as a gitlink but has no `.gitmodules`: root `git status` shows only `m shomajsetu` and `git submodule ...` fails. Inspect, diff, and commit app changes inside `shomajsetu/`.
- Root `package.json` is just a stale auth dependency list; thousands of `node_modules/` files are tracked there and no app source lives there. Install/run app deps in `shomajsetu/`, never at root. Root `.env.local` is untracked — don't commit it.
- READMEs are not setup docs: root README is only `# SomajSetu`; `shomajsetu/README.md` is stale create-next-app boilerplate pointing at the deleted `app/page.tsx`. Trust config/source.

## App: `shomajsetu/` (Next 16.4.6, React 19, Tailwind 4, JavaScript only)
- Commands run from `shomajsetu/`: `npm run dev`, `npm run lint` (plain `eslint`, flat config), `npm run build`. No test or `typecheck` script; `build` runs TypeScript and prerender checks.
- Routes live in `src/app/`, not `app/` (legacy root `app/` is deleted). Entrypoints: `src/app/layout.jsx`, `page.jsx`, `globals.css` (`@import "tailwindcss";`). Alias `@/*` -> `./`; shadcn/ui is JS-only (`components.json` `tsx: false`), primitives in `src/components/ui/`, `cn()` in `src/lib/utils.js`.
- `next.config.js`: `cacheComponents`, `partialPrefetching`, `agentFeedback`, Turbopack Tailwind loader. `next/image` allowlists only `images.unsplash.com`; other remote hosts are replaced with a fallback in `src/lib/eventData.js` (or must be added to the config).
- Auth: Better Auth email/password with JWT plugin + Mongo adapter (`src/lib/auth.js`); handler `/api/auth/[...all]`; client `src/lib/auth-client.js` (`getAuthToken()`); guard `src/components/ProtectedRoute.jsx` redirects to `/login?redirect=...`. `/login` and `/register` live in the `(auth)` route group; Navbar reads the live session and signs out. Private pages: dashboard, profile, create-event, manage-events, joined-events.
- Data: all event/profile reads and writes go through an external Express API via `src/lib/api.js` (`NEXT_PUBLIC_API_URL`, default `http://localhost:5000`; auto Bearer JWT). No backend source is in this repo, so data-driven pages can't load without it. `src/data/mockEvents.js` is unused reference data; `src/lib/eventData.js` normalizes API envelopes (`events`/`data`/...) and field variants (`_id`/`id`, `maxVolunteers`/`volunteersNeeded`, volunteer arrays, `email:`-prefixed join values).
- 404 fallbacks in `api.js` (don't "simplify" these away): organizer -> `/api/events/upcoming?organizer=`; joined events use `/api/events/upcoming?joinedBy=` primarily and `/api/users/:email/joined-events` as fallback; dashboard -> `null`. `/upcoming-events` only does `redirect("/events")`.
- Env: Next loads `.env*` only from `shomajsetu/`. Its gitignored `.env.local` is a copy of the root env (MONGODB_URI, DB_NAME, BETTER_AUTH_SECRET, BETTER_AUTH_URL, NEXT_PUBLIC_APP_URL, NEXT_PUBLIC_API_URL) — keep them in sync. App `.env*` and `next-env.d.ts` are gitignored.

## Next 16 / verification gotchas
- `shomajsetu/AGENTS.md` is regenerated by `next dev`; preserve its managed feedback blocks and follow it. Consult `shomajsetu/node_modules/next/dist/docs/` before writing Next 16 API code.
- With `cacheComponents`, `new Date()`/`Date.now()` during render breaks prerendering; fetch live data in client components instead. Dynamic routes reading `params` need `export const instant = false` (see `events/[id]/page.jsx`) because `Navbar` calls `usePathname()`.
- React 19 lint (`react-hooks/set-state-in-effect`) rejects synchronous `setState` in effects. Defer stateful loaders with `void Promise.resolve().then(load)`.
- Don't set route segment `runtime = "nodejs"` with `cacheComponents` — `next build` rejects it. Route handlers are Node by default here.
- `npm run build` warns that root `package-lock.json` is outside `shomajsetu`'s git repo but still passes; set `turbopack.root` only if that matters.
- Verify from `shomajsetu/`: `npm run lint`, then `npm run build` (both pass as of this writing). Never commit the root `.env.local`.
